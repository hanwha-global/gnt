# 국가별 해외진출 유의사항 탭

국내 증권사가 해외 자회사·관계사 설립이나 지분투자를 할 때 나라별로 확인할 점(외국인 지분, 인가, 최소 자본, 현지 임원·거주, 송금·외환·세금)과 한국 측 공통 절차를 한 표로 봅니다.

- `data/countries.json`: 사람이 출처를 보고 쓰는 요약. 항목마다 출처 번호(`src`)와 확인 여부(`ok`; false 이면 화면에 '요확인'), 나라마다 검증일(`checked`).
- `data/detected.json`: `.github/workflows/guide-daily.yml` 이 매일 07:10(KST) 감독당국 공식 도메인 발표 중 진입 규제 키워드가 걸린 것을 모은 결과(LLM 없음). 검증일 이후 발표가 있으면 표에 '● 신규 공식 발표'가 뜹니다. 요약 문구는 자동으로 바꾸지 않습니다.
- 국내사 현지법인 수는 국내 탭 기준 데이터(`site/data/domestic/seed.json`)에서 셉니다.
- 한국 측 절차는 해외지분투자 Workflow 탭(`workflow/data/steps.json`)이 원본이라 대외 신고·보고 단계만 링크로 보여줍니다. 당사 진행 건과 실제 마감일은 한화투자증권 탭.

갱신 방법: 신규 발표를 확인해 `countries.json` 문구를 고친 뒤 그 나라 `checked` 를 그날로 바꾸면 '신규' 표시가 사라집니다.
